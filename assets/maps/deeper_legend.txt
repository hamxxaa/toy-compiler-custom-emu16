# Deeper MINE legend (tools/pixel_map.py). Each PNG palette index -> a tile id (PPU pattern slot) + its
# property flags. Tile ids match the slots the game DMAs art to: 1=dirt 2=stone 3=dirt-bg 6=ladder
# 7=ore 8=lava. Flag bits are the code's meaning: bit 0 = solid, bit 2 = diggable (F_DIG),
# bit 3 = hazard (F_HAZARD), bit 4 = ore (F_ORE).
flags solid=0 dig=2 ore=4 hazard=3
0 1 solid dig       # dirt   -- solid, diggable
1 2 solid           # stone  -- solid border / cap
2 3                 # dirt background -- visible but NOT solid (walk / fall through)
3 6                 # ladder -- NON-solid; drop into it to descend, press UP at it to climb out
4 7 solid dig ore   # ore    -- solid, diggable, drops ore
5 8 solid hazard    # lava   -- solid, NOT diggable, hurts on contact
# Sizing entries (indices unused by the mine PNG) so the shared tile_flags also covers the SURFACE
# tiles the game loads from deeper_enterance_map: grass = tile 4, base = tile 5.
6 4 solid           # grass
7 5 solid           # base
