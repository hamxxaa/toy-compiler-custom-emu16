# Deeper map legend (tools/pixel_map.py). Each PNG palette index -> a tile id (PPU pattern slot) + its
# property flags. The tile ids match the slots the game DMAs art to: 1 = dirt, 2 = stone, 3 = dirt bg.
# Flag bits are the code's meaning: bit 0 = solid (physics/dig tests it), bit 2 = diggable (F_DIG).
flags solid=0 dig=2
0 1 solid dig     # dirt  -- solid, diggable
1 2 solid         # stone -- solid border, not diggable
2 3               # dirt background -- visible but NOT solid (walk / fall through)
